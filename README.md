#### 🔭 Projet principal

**[supervision-si](https://github.com/freg/supervision-si)** — une couche de supervision posée au-dessus d'un SI existant.
Un hub web (React + Flask, sous Docker, authentification Keycloak/LDAP) regroupe une soixantaine de modules :
- tickets et SAV ;
- coffre-fort de secrets, PKI interne ;
- exploration réseau (sondes, SNMP, cartographie) ;
- agents installés sur les postes Windows, macOS et Linux ;
- sauvegarde et restauration, DBA, IPAM, onduleurs.

Il s'installe en une commande (`./install.sh`), qui adapte le périmètre déployé à la machine.
